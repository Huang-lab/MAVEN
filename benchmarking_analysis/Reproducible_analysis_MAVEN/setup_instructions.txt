The following scripts and directory systems facilitate ...
(A) benchmarking evaluation of MAVEN on MAVEDB test sets
(B) benchmarking evaluation of MAVEN on ProteinGym MAVE datasets

REQUIRED FILES:
ProteinGym resource files (specified in instructions below) can be found at: https://proteingym.org/
MAVEN proteome-wide predictions can be found at: https://zenodo.org/records/14861747

The analysis reported in the MAVEN manuscript is conducted using filenames and dependencies from ProteinGym_v1.3 (as of August 2025). In the event that ProteinGym updates cause errors in the script, ProteinGym v1.3 can be found here: https://zenodo.org/records/15293562

Notin, Pascal et al. “ProteinGym: Large-Scale Benchmarks for Protein Design and Fitness Prediction.” bioRxiv : the preprint server for biology 2023.12.07.570727. 8 Dec. 2023, doi:10.1101/2023.12.07.570727. Preprint.

Rubin, A.F., Stone, J., Bianchi, A.H. et al. MaveDB 2024: a curated community database with over seven million variant effects from multiplexed functional assays. Genome Biol 26, 13 (2025). https://doi.org/10.1186/s13059-025-03476-y
==============================================================================================================
INSTRUCTIONS:
0. Ensure your file directory system matches what is shown below. 
1. To set up ProteinGym benchmarking subdirectory...
    (a) Navigate to resource_data > proteingym_data
    (b) Go to https://proteingym.org/download
    (c) Download Model Scores > Zero-Shot DMS Assay Scores > Zero-shot substitutions (directory name should be zero_shot_substitutions_scores)
    (d) Download Reference Files > DMS > Substitutions (file name should be DMS_substitutions.csv)
    (e) Download Data > DMS Assays > Substitutions (directory name should be DMS_ProteinGym_substitutions; will be ~40 GB)

2. To pull relevant MAVEN proteome predictions...
    (a) Run the script collect_MAVEN_predictions.py from the terminal, passing the path to MAVEN proteome-wide predictions and the path to Reproducible_analysis_MAVEN/resource_data.
        Example: python collect_MAVEN_predictions.py ../../path/to/proteome_wide_predictions/ resource_data/
        This will add the following to the resource_data subdirectory: s12-proteome-wide-predictions-maven-benchmarking (needed for testing_mave_dataset_benchmark.ipynb) and MAVEN_predictions (needed for ProteinGym_benchmark.ipynb)

3. Run setup_maven_env.sh
    (a) From terminal, run "chmod +x setup_maven_env.sh" to make script executable
    (b) From terminal, run "./setup_maven_env.sh" to set up conda environment, install packages, and add to kernel (for Jupyter notebook)

* ProteinGym_benchmark.ipynb : Analysis script to perform MAVEN benchmarking against ProteinGym MAVEs/VEPs
* testing_mave_dataset_benchmark.ipynb : Analysis script to perform MAVEN benchmarking against MAVEDB MAVEs

* requirements.txt : contains all necessary packages and versions (compatible with Python=3.10)
* setup_maven_env.sh : bash script to set up python version, project conda environment, and install package dependencies.
* collect_MAVEN_predictions.py : python script to pull the relevant subset of variant scores from MAVEN proteome-wide predictions.
