# MAVEN benchmarking analysis pipeline

<span style="font-size:20px"> This analysis script scores, benchmarks, and visualizes the performance of MAVEN against other VEPs on MAVEDB and ProteinGym validation datasets, as presented in the MAVEN manuscript. It is designed to function independently of the training pipeline; the training pipeline outputs a directory "maven_v1.0.0/" which is provided here for your convenience. Please follow the instructions in setup_instructions.txt to ensure the resource_data subdirectory is set-up appropriately with file dependencies from ProteinGym and variant scores from MAVEN proteome-wide predictions. Conda is required for environment and package management to run the provided analysis notebooks.  </span>

[ProteinGym Benchmarking Platform](https://proteingym.org/)
[MAVEN proteome-wide predictions](https://zenodo.org/records/14861747)
